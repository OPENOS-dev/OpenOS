## OpenScript 是标签语法
- 用户强调 OpenScript 是基于 XML 标签语法的语言，语法格式: `<标签名 属性="值">内容</标签名>`
- 不是 C/Go 风格的 struct/enum/函数签名语法
- 包管理器 OPT/OPK 相关概念不应该混入 OpenScript 语言本身的标签设计中（那属于模块逻辑层）

  - `.bazelversion` — 锁定 Bazel 7.1.0（ChromiumOS R151 工具链）
  - `.bazelrc` — 默认平台 //profiles/base:openos_amd64，禁用 Google branding
  - `BUILD.bazel` — 根级包定义
  - `chromeos-base/openos-theme/BUILD.bazel` — CSS 主题文件安装 + 符号链接 (pkg_files + pkg_mklink)
  - `chromeos-base/openos-meta/BUILD.bazel` — 元包，用 config_setting + select() 代替 USE flags
  - `profiles/base/BUILD.bazel` — platform constraints (openos_branding/fdroid/opk/no_telemetry)

  - RDEPEND → pkg_tar deps
