# 2026-07-21

## 品牌去 Google 化 — platform2 源码全量扫描

### 起因
- 用户要求 "Check out Chrome 浏览器所有代码"，但因代理配额 500MB 不可行
- Chromium 源码即使浅克隆也需 1-3GB，完整 checkout 需 30-40GB
- 改为对已有 `platform2/` 源码做全量品牌清理

### 改动范围（450+ 文件）

**Upstart .conf 文件（288 个）：**
- `description "Chrome OS ..."` → `description "Open-OS ..."`
- `description "ChromeOS ..."` → `description "OpenOS ..."`
- `author ...@chromium.org` / `@google.com` → `@opencodestudio.org`

**DIR_METADATA（117 个）：**
- `team_email: "xxx@google.com"` → `team_email: "openos-dev@opencodestudio.org"`

**硬件配置（20 个 YAML）：**
- 形态枚举重命名：CHROMEBASE→OPENBASE, CHROMEBIT→OPENBIT, CHROMESLATE→OPENSLATE, CHROMEBOOK→OPENBOOK, CHROMEBOX→OPENBOX
- schema.json 和 cros_config_schema.yaml 同步更新
- 20 个 overlays/ YAML 配置文件同步替换

**源码修改（30+ 文件）：**
- crosh: arc.rs 测试域名 google.com→example.com, u2f_flags.rs relying party
- arc: adbd.cc USB manufacturer google→OpenOS
- metrics: metrics_daemon_main.cc 程序名, upload_url, system_profile_cache 常量名
- crash-reporter: crash_sender_base.cc GOOGLE_CRASH_ID, crash_sender_util.h upload URLs, 多个 main.cc 程序名
- cryptohome: fido_utils.cc icon URL, backend_cert_verify.cc 团队邮箱, crypto.h bug 链接
- debugd: dev_features_password_utils.cc groups.google.com 链接
- u2fd: webauthn_handler.cc kGoogleRpId→kOpenOSRpId
- crash-reporter: gsc_collector_base.cc google_security_chip→openos_security_chip
- diagnostics: ground_truth_constants.h 形态常量重命名
- permission_broker: rule_utils.h/.cc FormFactor 枚举, feature flag 名
- primary_io_manager: RunningOnChromebox→RunningOnOpenBox, featured_flag 名
- login_manager: chrome_setup.cc ChromeboxForMeeting→OpenBoxForMeeting, DIR_METADATA
- installer: chromeos_postinst.cc/legacy 中 NonChromebook→NonOpenOS
- minios: draw_utils.cc 默认 HWID
- chromeos-config: schema README 描述文本
- 80+ 文件注释中的 Chromebook/Chromebox→Open-OS device/OpenBox

### 关键设计决策
- 形态枚举 CHROMEBOOK→OPENBOOK 等属于功能性更改，与 YAML 配置必须同步
- `FormFactor` 枚举从 `kChromebox` 改为 `kOpenBox`
- Crash/metrics 上传 URL 改为 opencodestudio.org 占位域名
- 第三方库描述（protobuf 等）和纯代码标识符（kChromeOsProduct 等）未修改
- 文件路径 `/opt/google/chrome/chrome` 未修改（二进制安装路径，不是品牌问题）

## ebuild 层二进制路径去品牌化（6 文件，11 处路径）

### 修改策略
仅修改自包含、无交叉依赖的文本配置文件/脚本：
- 自己的 ebuild（openos-base）— 完全可控
- TCON 文本配置/脚本（.ini + .sh）— 自包含，修改后路径内部一致
- 其余 27 处刻意保留（固件/DSP 二进制、ARCVM Android 容器路径、BSP touch 脚本有外部依赖）
